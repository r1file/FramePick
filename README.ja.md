# FramePick

[简体中文](README.md) · [English](README.en.md) · 日本語

長いローカル動画から、既定 5 秒の範囲を動かして見どころを選び、クリップごとに個別の GIF をまとめて作成するデスクトップツールです。動画全体を画像に取り込む処理は行いません。

## はじめに

[Releases](https://github.com/r1file/FramePick/releases) から Windows 用の単一 EXE をダウンロードして実行します。Python、Qt、FFmpeg/ffprobe、表示用フォントを同梱しており、インストールや PATH 設定は不要です。起動時に一時フォルダーへ展開するため、空き容量が必要です。

1. 動画を開くか、ウィンドウへドロップします。最初のフレームを一時停止状態で表示します。
2. 時間範囲を移動し、**A** で追加します。長さと基準位置を変更できます。
3. **L** でループ確認、**S** で元の解像度の PNG を保存します。
4. 複数のクリップを選んで「すべて GIF に書き出す」を押します。

**Space** で再生 / 一時停止、**M** でミュート、スピーカーにカーソルを重ねて音量を調整できます。**↑ / ↓** で追加済みクリップを切り替えます。微調整タイムラインはホイールで拡大し、範囲を端で保持すると自動スクロールします。復元した未再生のクリップも単一フレームのサムネイルを生成します。

英語・簡体字中国語・日本語に対応し、右上または言語メニューですぐに切り替えられます。Noto Sans / SC / JP と JetBrains Mono を同梱し、日本語では日本語用の字形を使用します。他の文字体系はシステムのフォントへフォールバックします。

設定と復元データは EXE の隣の `FramePick.data` に保存します。書き込み不可の場合はユーザーデータへ保存します。プロジェクトには時刻と動画の場所を記録し、元の動画は複製しません。

## 開発・制限

Python 3.11 以上。構築手順は [English README](README.en.md) を参照してください。Windows は実機で確認し、Linux/macOS は GitHub Actions の実際の結果を確認してください。Linux は互換性のある glibc とデスクトップ環境が必要です。macOS 版は未署名です。

GIF は無音です。ライブ配信・DRM・オンライン動画の取得・HDR の専用トーンマッピング・字幕焼き込みには対応していません。圧縮動画へのシークでは直前のキーフレーム付近の読み込みが発生します。
